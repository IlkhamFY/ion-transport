# Ion transport

Experimental conductivity, diffusivity and activation energy for lithium and sodium ion conductors, mined from the literature.

The open file is CC BY. It holds 13466 records from 1888 papers (1880 with a DOI) and 1651 formulas. The lithium and sodium rows are 7078, from 1044 papers and 1052 formulas. 4320 of those rows are the measured view. Tier A is 1407 rows. 2402 rows are flagged curated gold; an agent checked them, and a person has not.

A second file holds 1355 numeric facts from 265 articles that are not CC BY. That file is released under CC BY 4.0. Each row keeps the licence of the source article. Those rows are not included in the 13466, and they are not Tier A. 231 of them would pass the mechanical Tier A gate; the flag records that and does not promote them.

No model score is in this release. The reference list has 33 materials with a measured activation energy (21 marked for scoring). The potential runs are still going.

## What is where

`data/` holds the tables. `code/loader.py` reads the open parquet. `docs/DATA.md` defines the columns, the two licences, and the counts. `docs/` is the same tables in a browser. GitHub Pages serves that folder.
